Contato

Envie uma mensagem com uma descrição objetiva do que aconteceu.

dezoapps@gmail.com

Quando possível, informe o modelo do aparelho, o sistema operacional, a versão do Aloha e o código de erro exibido.

Salas e partidas

Se uma sala não conectar ou uma partida for interrompida, informe o horário aproximado, a plataforma e o ponto em que o problema ocorreu. Não envie senhas ou dados pessoais sensíveis.

Denunciar conteúdo

Se alguém enviar uma resposta ofensiva ou inadequada durante uma partida, use a opção de ocultar disponível para quem conduz a sala e envie uma denúncia pelo e-mail de suporte. Informe o horário, o jogo e o apelido exibido. Não repita o conteúdo ofensivo se isso não for necessário para a análise.

Compras e assinaturas

Cancelamentos, reembolsos e renovações são gerenciados pela App Store ou pelo Google Play. Para investigar uma falha de restauração, informe a plataforma e o identificador da transação. Não envie dados de cartão.

Privacidade e exclusão

Para conhecer os dados tratados pelo app, consulte a Política de Privacidade. Para apagar dados associados ao Aloha, siga as instruções da página de exclusão.
