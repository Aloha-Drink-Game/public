Exclusão de dados

Como apagar dados locais ou solicitar a exclusão de dados associados ao Aloha.

Última atualização: 13 de outubro de 2026

O Aloha não exige uma conta. Mesmo assim, você pode solicitar a exclusão de dados associados a uma compra, instalação ou atendimento.

Como solicitar

  1. Envie um e-mail para dezoapps@gmail.com com o assunto “Exclusão de dados do Aloha”.
  2. Informe a plataforma usada, Android ou iOS.
  3. Se a solicitação envolver uma compra, inclua o identificador da transação fornecido pela loja. Não envie número de cartão, senha ou documento pessoal.
  4. Se disponível, inclua o identificador anônimo do Premium ou outra informação técnica exibida pelo suporte do app.

Confirmaremos o recebimento e informaremos quando a solicitação for concluída ou quando precisarmos de outra informação técnica para localizar os dados.

Dados apagados mediante solicitação

  • dados localizáveis no RevenueCat associados ao identificador informado;
  • dados de suporte mantidos diretamente pelo desenvolvedor, quando aplicável;
  • outros dados sob controle do Aloha que possam ser associados com segurança à solicitação.

Dados apagados automaticamente

Dados operacionais de uma sala expiram automaticamente, atualmente em até seis horas. Dados locais podem ser apagados pelo próprio usuário limpando os dados do app ou desinstalando-o.

Dados que podem ser mantidos

Registros de compra, reembolso, fraude, segurança ou obrigações fiscais podem ser mantidos pelo prazo exigido por lei ou pelas regras da App Store, Google Play e respectivos provedores. Dados agregados ou sem vínculo razoável com uma pessoa também podem ser mantidos.

Não envie senha, código de acesso, número completo de cartão, CPF ou outro documento para solicitar exclusão.
